VIVA QUESTIONS AND ANSWERS
Q1. What is the aim of this practical?
A. To predict Uber fare and compare Linear Regression with Random Forest Regression using regression metrics.

Q2. Why is this a regression problem?
A. The output, fare_amount, is a continuous numerical value.

Q3. What is preprocessing?
A. Cleaning and transforming raw data into a form suitable for analysis and modelling.

Q4. Why do we use df.info()?
A. To inspect column names, data types, non-null counts and memory usage.

Q5. Why check missing values?
A. Many models cannot accept missing values directly, and missing data can distort results.

Q6. What does dropna() do?
A. It removes rows containing missing values by default. This can reduce the dataset, so the amount of data removed should be checked.

Q7. Why convert pickup_datetime to datetime?
A. To correctly extract date/time components such as hour, day, month and year.

Q8. Why drop key and Unnamed: 0?

Q9. What is an outlier?
A. An observation unusually far from the rest of the data.

Q10. Explain the IQR method.
A. Calculate Q1 and Q3, find IQR=Q3-Q1, then flag values below Q1-1.5×IQR or above Q3+1.5×IQR as potential outliers.

Q11. Why might fare outliers be removed?
A. Extremely large or invalid fares can affect the model and metrics. But genuine long-distance/high-cost rides may also be outliers, so they should not be removed blindly.

Q12. What does correlation +1 mean?
A. Perfect positive linear association. -1 means perfect negative linear association, and 0 means no linear association.

Q13. Does correlation prove causation?
A. No. Correlation describes association, not cause and effect.

Q14. What is Linear Regression?
A. A model that estimates a target as a linear combination of input features.

Q15. What is Random Forest Regression?
A. An ensemble model that trains multiple decision trees and combines their predictions, commonly by averaging.

Q16. What is the difference between Linear Regression and Random Forest?
A. Linear Regression fits a linear relationship; Random Forest can learn more complex nonlinear patterns but is often less interpretable and can use more resources.

Q17. Why use train_test_split?
A. To evaluate performance on data not used to fit the model.

Q18. What does test_size=0.2 mean?
A. 20% of the data is reserved for testing and 80% for training.

Q19. What is R²?
A. A score comparing the model with predicting the target mean. A value closer to 1 is generally better; 0 means performance similar to the mean baseline, and negative values can occur.

Q20. What is RMSE?
A. Root Mean Squared Error: sqrt(mean((actual-predicted)^2)). It is in the same units as the target and penalizes large errors more strongly.

Q21. What is MAE?
A. Mean Absolute Error: mean(abs(actual-predicted)). It measures average absolute prediction error in target units.

Q22. Which model is better?
A. Compare on the same test set. Prefer higher R² and lower RMSE/MAE, while also considering runtime and generalization. Do not claim a winner without the actual scores.

VIVA QUESTIONS AND ANSWERS
Q1. What is spam detection?

Q2. What is classification?

Q8. What is SVM?
A. Support Vector Machine, a supervised algorithm that finds a decision boundary with a large margin between classes.

Q9. What is LinearSVC?
A. A linear support-vector classifier that learns a linear decision boundary.

Q10. What are support vectors?
A. Training examples that lie closest to the decision boundary and strongly influence the margin.

Q11. What is a hyperplane?
A. A decision boundary; in two dimensions it is a line, and in higher dimensions it is a hyperplane.

Q12. What is accuracy?
A. Correct predictions divided by all predictions. It may be misleading when classes are imbalanced.

Q13. Why use classification_report?

Q14. Why use random_state=42?
A. To make the random train/test split reproducible.

Q15. How should we compare KNN and SVM?
A. Compare accuracy and per-class precision, recall and F1-score on the same test split. For spam filtering, false negatives and false positives can have different costs.

Q16. What is a false positive here?
A. A legitimate email incorrectly classified as spam.

Q17. What is a false negative here?
A. A spam email incorrectly classified as legitimate.

Q18. Why might SVM perform well on word-frequency features?

PRACTICAL 4 — GRADIENT DESCENT
Minimize y = (x + 3)² starting from x = 2
============================================================

YOUR NOTEBOOK'S CODE FLOW
1. Define f(x)=(x+3)**2.
2. Define derivative f'(x)=2*(x+3).
3. Initialize x=2.0, learning_rate=0.1 and iterations=100.
4. Repeat: x = x - learning_rate * derivative(x).
5. Save each x in history.
6. Plot the function and the gradient-descent steps.

MATHEMATICAL IDEA
For f(x)=(x+3)²:
f'(x)=2(x+3)
Set derivative to zero: 2(x+3)=0, so x=-3.
At x=-3, y=0, which is the global minimum for this parabola.

VIVA QUESTIONS AND ANSWERS
Q1. What is Gradient Descent?
A. An iterative optimization algorithm that updates parameters in the direction opposite the gradient to reduce the objective function.

Q2. What is a gradient?
A. The derivative in one dimension, or vector of partial derivatives in multiple dimensions, describing the direction of steepest increase.

Q3. Why subtract the derivative?
A. The derivative points toward increasing values locally; subtracting it moves toward decreasing values.

Q4. What is the learning rate?
A. The step-size multiplier controlling how far each update moves.

Q5. What happens if the learning rate is too large?
A. Updates may overshoot the minimum or diverge.

Q6. What happens if the learning rate is too small?
A. Convergence may be very slow.

Q7. What is the update rule?
A. x_new = x_old - learning_rate × f'(x_old).

Q8. What is the derivative of (x+3)²?
A. 2(x+3), using the chain rule.

Q9. What is the minimum point?
A. x=-3 and y=0.

Q10. Why start from x=2?
A. It is the initial point from which the iterative updates begin; the algorithm moves toward the minimum.

Q11. What is convergence?
A. When successive updates or the objective value become sufficiently close to a stable solution.

Q12. Is gradient descent guaranteed to find the global minimum?
A. Not for every function. It depends on the function's shape, learning rate and initialization. For this convex quadratic, it converges to the global minimum with a suitable learning rate.

Q13. What does history store?
A. The sequence of x values generated during optimization, used to visualize the steps.

Q14. Why plot the steps?
A. To show how the algorithm moves along the curve toward the minimum.

PRACTICAL 6 — CUSTOMER SALES CLUSTERING
K-Means, Hierarchical Clustering and Elbow Method
============================================================

AIM

6. Plot k against WCSS to inspect the elbow.
7. Fit KMeans with n_clusters=3 and obtain cluster labels.
8. Fit AgglomerativeClustering(n_clusters=3) and obtain hierarchical cluster labels.

KEY CONCEPTS
- Clustering is unsupervised learning: no target labels are supplied.
- K-Means assigns points to clusters based on distance to cluster centroids.
- A centroid is the mean position of points assigned to a cluster.
- WCSS/inertia is the sum of squared distances from each sample to its assigned cluster center.
- As k increases, WCSS generally decreases.
- The elbow method looks for a point where adding more clusters produces diminishing improvement.
- Hierarchical clustering builds a hierarchy of clusters; agglomerative clustering starts with individual points and merges them.
- StandardScaler is important for distance-based clustering when features have different scales.

VIVA QUESTIONS AND ANSWERS
Q1. What is clustering?
A. Grouping data points by similarity without known target labels.

Q2. What is the difference between supervised and unsupervised learning?
A. Supervised learning uses labelled examples; unsupervised learning looks for structure without target labels.

Q3. Explain K-Means.
A. Initialize k centroids, assign points to the nearest centroid, update centroids to cluster means, and repeat until assignments/centroids stabilize or a stopping condition is met.

Q4. What is k in K-Means?
A. The number of clusters to form.

Q5. What is WCSS?
A. Within-Cluster Sum of Squares, also called inertia in scikit-learn KMeans: the sum of squared distances from samples to their assigned centroids.

Q6. Why does WCSS decrease as k increases?
A. More clusters allow points to be closer to their assigned centroid; at the extreme, one cluster per point can give zero inertia.

Q7. What is the elbow method?
A. Plot WCSS against k and choose a k near the bend where further increases yield smaller gains.

Q8. Does the elbow method always give one obvious answer?
A. No. The bend can be ambiguous; domain knowledge and other cluster-quality measures may also help.

Q9. Why standardize features?
A. To prevent large-scale features from dominating distance calculations.

Q10. What is random_state=42 used for in KMeans?
A. It makes the random initialization reproducible.

Q11. What does n_init=10 mean?
A. Run the algorithm with 10 centroid initializations and retain the best result according to inertia.

Q12. What is hierarchical clustering?
A. A method that creates nested clusters, often represented by a dendrogram.

Q13. What is agglomerative clustering?
A. A bottom-up hierarchical approach: begin with each point as its own cluster and merge clusters until the requested number remains.

Q14. Do K-Means and hierarchical cluster labels mean the same thing?
A. No. Labels are arbitrary identifiers. Cluster 0 from one algorithm is not automatically equivalent to cluster 0 from another.

Q15. Why select numeric columns?
A. These clustering algorithms require numerical input in this implementation. Categorical variables would need suitable encoding or a different method.

Q16. What is a limitation of dropping columns with any missing value?
A. It may discard useful features. Alternatives include imputation or carefully chosen feature selection.

Q17. What are limitations of K-Means?
A. It requires k in advance, is sensitive to initialization and outliers, and works best for roughly compact, spherical clusters under Euclidean distance.

IMPORTANT CODE REVIEW NOTES

- The code uses numeric columns only. Numeric identifiers or codes may be included even if they are not meaningful distance features. Review the selected columns before clustering.

- StandardScaler is fitted and applied to the full dataset before clustering, which is normal when clustering all available unlabeled data. For a predictive evaluation pipeline, preprocessing should be fitted within the training split.

CROSS-PRACTICAL QUICK REVISION

1. Regression vs classification:
   - Regression predicts continuous numbers (Uber fare).
   - Classification predicts categories (spam, diabetes outcome, churn).

2. Supervised vs unsupervised:
   - Supervised: known target labels (Uber, spam, churn, diabetes).
   - Unsupervised: no target labels (sales clustering).

3. Train/test split:
   - Training set fits the model.
   - Test set estimates performance on unseen data.
   - Never fit preprocessing such as StandardScaler on the test set when evaluating a supervised model.

4. Common Python libraries:
   - pandas: data loading and manipulation.
   - NumPy: numerical operations.
   - Matplotlib/Seaborn: plots.
   - scikit-learn: splitting, preprocessing, models and metrics.

5. Common data functions:
   - pd.read_csv(): load CSV.
   - df.head(): preview rows.
   - df.info(): inspect schema and non-null counts.
   - df.isnull().sum(): count missing values per column.
   - train_test_split(): create train/test sets.
   - fit(): train a model or fit a transformer.
   - transform(): apply a fitted transformation.
   - fit_transform(): fit and transform.
   - predict(): generate predictions.

6. Common pitfalls:
   - Do not use target columns as input features.
   - Do not fit scalers on test data.
   - Do not compare models on different test splits.
   - Accuracy alone can hide poor performance on imbalanced classes.
   - Verify dataset column names and label encoding.
   - Check for leakage, invalid values, missing data and outliers.

7. Metric memory aid:
   - R²: higher is generally better.
   - RMSE/MAE: lower is better.
   - Accuracy: fraction correct.
   - Precision: reliability of positive predictions.
   - Recall: fraction of actual positives found.
   - F1-score: harmonic mean of precision and recall.
   - Confusion matrix: counts of correct/incorrect class predictions.
   - WCSS: lower with more clusters; use the elbow to balance fit and complexity.
